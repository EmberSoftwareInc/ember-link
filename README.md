# Firmware recommendation metadata

This branch contains no firmware source. Do not merge it into main or dev.

`dev.json` is the development catalog; an empty list means no development build
is currently recommended. Published images remain in immutable tagged releases.

Use `tools/release.py recommend-dev` or `withdraw-dev` from the source checkout.
See [the release lifecycle](https://github.com/EmberSoftwareInc/ember-link/blob/main/docs/release-lifecycle.md).
